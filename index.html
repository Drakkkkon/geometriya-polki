Инструкции

Как подключить папку Google Диска

Вариант 1. Вход в Google. Подходит любая папка вашего Диска, в том числе закрытая.

  1. Откройте console.cloud.google.com. Выберите тот же проект, что для Google Таблицы, или создайте новый.
  2. Меню «API и сервисы», затем «Библиотека». Найдите Google Drive API и нажмите «Включить».
  3. «API и сервисы», «Учётные данные», «Создать учётные данные», «Идентификатор клиента OAuth». Тип: «Веб-приложение». В «Разрешённые источники JavaScript» добавьте адрес сайта: https://drakkkkon.github.io (без слэша в конце и без названия папки).
  4. «Экран согласия OAuth»: добавьте свою почту в «Тестовые пользователи».
  5. Скопируйте «Идентификатор клиента» в поле Client ID выше. Оно общее с Google Таблицей.
  6. Нажмите «Импортировать фото из папки…» и разрешите просмотр файлов Диска (только чтение). Если Google пишет «приложение не проверено», нажмите «Дополнительно», затем «Перейти»: это ваше личное приложение.

Вариант 2. Папка по ссылке и API-ключ. Без входа в аккаунт, но папка должна быть открыта по ссылке.

  1. В консоли Google включите Google Drive API (шаг 2 выше).
  2. «Учётные данные», «Создать учётные данные», «Ключ API». Скопируйте ключ в поле выше. Лучше нажать «Ограничить ключ»: API — только Drive API, сайты — https://drakkkkon.github.io/*.
  3. В Google Диске нажмите на папке правой кнопкой, «Поделиться», доступ «Все, у кого есть ссылка», роль «Читатель». Скопируйте ссылку в поле «Ссылка на папку».

Как назвать фото: 10065.jpg — обложка книги №10065, 10065_корешок.jpg — её корешок. Если имена обычные (IMG_0412.jpg), нейросеть прочитает надписи на фото и найдёт книгу сама. Перед применением вы увидите список и сможете всё поправить.

Как получить бесплатный ключ Gemini
  1. Откройте aistudio.google.com/apikey и войдите в аккаунт Google.
  2. Нажмите «Create API key» («Создать ключ API»). Банковская карта не нужна.
  3. Скопируйте ключ в поле «Ключ Gemini» выше. Он хранится только в этом браузере.
  4. Модель по умолчанию gemini-2.5-flash. Если Google её отключит, впишите другую модель «flash» или «flash-lite» с бесплатным уровнем (список на ai.google.dev/gemini-api/docs/models).
  5. У бесплатного уровня есть лимиты в минуту и в день. Программа делает паузы между фото сама. Если дневной лимит кончился, продолжите завтра: разобранные фото запоминаются.

На время разбора фото отправляются в Google. Если это не подходит, выберите нейросеть «На устройстве».

Какую нейросеть выбрать
  1. COCO-SSD и чтение надписей — для начала. Один раз скачается около 25 МБ, фото остаются на вашем устройстве. Хорошо находит книги, когда на фото одна или несколько книг.
  2. Gemini — если на фото много книг сразу или надписи мелкие: лучше всех читает русские и казахские буквы. Нужен бесплатный ключ, фото уходят в Google.
  3. OWL-ViT — ищет «обложку» и «корешок» по описанию. Скачивается около 150 МБ, нужен мощный компьютер. Экспериментальный вариант.
  4. Без нейросети — самый быстрый: книга определяется по номеру в имени файла (10065.jpg), лишние поля обрезаются по цвету фона.

Нейросети и языки для чтения надписей загружаются с сайтов jsdelivr.net и projectnaptha.com, нужен интернет.

Папка с компьютера

Программа берёт фото из папки по номеру книги: 10065.jpg это обложка, 10065_корешок.jpg это корешок. Подойдёт и папка выгрузки Telegram Desktop.

Открытый канал Telegram

Фото берутся по ссылкам из столбца «Telegram пост». Нужен свой бесплатный Worker (адрес-посредник): так Telegram разрешает забрать картинки. Или используйте выгрузку Telegram Desktop через папку выше.
