Геометрия Полки, версия 1.0.0
(раньше проект назывался «Полка-конструктор», предыдущая версия 0.2.1)

Как открыть
  Распакуйте архив и откройте index.html в браузере на компьютере или телефоне.
  Папка vendor должна лежать рядом с index.html (в ней библиотека для Excel).
  Интернет нужен только для шрифтов, без него страница работает на системных.

Что внутри
  index.html          вся программа
  vendor/             библиотека JSZip для чтения и записи .xlsx (работает без интернета)
  GITHUB.md           как выложить проект на GitHub и включить сайт
  README.txt          этот файл

Размеры (мм)
  Полка 1000 x 260 x 240 (стандарт 100*260*240, первое число принято как 100 см).
  У каждой книги свои размеры из таблицы: «Высота (Длина)» x «Ширина» x «Корешок».
  Если размера нет или столбец выключен при загрузке, берётся прежняя книга 210 x 140 x 35.

Что изменилось в 1.0.0
  - Данные настоящие: встроен лист «228 С 15.10» (34 записи, 36 экземпляров), переплёт взят по коду
    из листа «Генеральная».
  - Каждая запись: свои размеры, название и автор на корешке и обложке. Цвета не более пяти,
    у одного автора один цвет.
  - Твёрдый переплёт: тёмные торцы и канавки на корешке. Мягкий: гладкий корешок с тонкой линией.
    Не указан: простой корешок.
  - Количество на складе больше 1 даёт несколько экземпляров (до 10), у каждого «Экземпляр 1 из 2».
  - Нажатие на книгу открывает полное описание из таблицы: номер в каталоге, автор, название, год, цена,
    место хранения, количество, размеры, вес, состояние и примечание к состоянию, переплёт, ссылка и др.
  - Лежачая книга лежит на самых высоких стоящих под ней (книги теперь разной высоты); стоящая не может
    быть выше уровня, на котором лежит книга над ней.
  - Книги притягиваются вплотную друг к другу, поэтому на полку помещается весь лист.
  - Кнопки «Загрузить из Excel» и «Выгрузить в Excel» работают.
  - Многотомники из версии 0.2 убраны: в таблице том не отдельная запись, а одна книга со своей толщиной.

Загрузка из Excel
  1. Нажмите «Загрузить из Excel» и выберите файл .xlsx.
  2. Выберите лист. Листы без заголовка (как «228 С 15.10») читаются по столбцам листа «Генеральная».
  3. Отметьте, брать ли данные с листа «Генеральная» по коду книги (переплёт, формат и другие столбцы,
     которых нет на выбранном листе).
  4. Выберите столбцы. По умолчанию включены все. Выключенный столбец не используется:
     без размеров берутся 210 x 140 x 35, без «Количество на складе» одна книга на запись.
  5. «Загрузить». С листа берутся первые 150 записей, на экране не больше 300 книг.

Выгрузка в Excel
  Файл Geometriya-Polki_<лист>.xlsx: лист «Полка» (все выбранные столбцы плюс «Положение», «Позиция, мм»,
  «Ориентация», «Экземпляр») и лист «Сведения». Такой файл можно загрузить обратно: расстановка книг
  восстановится (столбцы положения должны быть включены).

Ограничения
  - Только .xlsx (не старый .xls). Формулы читаются по сохранённым значениям.
  - Длинные названия на тонком корешке обрезаются многоточием, полное название есть в описании книги.
  - Тест без счёта, как и раньше.
