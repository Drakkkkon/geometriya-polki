# Фото книг из папки Google Диска

Программа может сама взять фотографии из папки на вашем Google Диске, найти на них обложки и корешки книг,
обрезать лишнее, повернуть корешки и вставить фото в нужные книги на полке.
Нейросети для этого бесплатные и работают в вашем браузере (или по вашему бесплатному ключу Google Gemini).

Открыть: меню **Фото → Фото из Google Диска…** или **Настройки → Фото из Google Диска**.
Те же инструкции есть в самом низу окна «Настройки», свёрнутым блоком «Инструкции».

## Что нужно подготовить

1. Папка на Google Диске с фото. Вложенные папки читаются (можно отключить).
2. Способ открыть папку. Выберите один из двух.

### Вариант 1. Вход в Google (подходит любая папка, в том числе закрытая)

1. Откройте https://console.cloud.google.com/ и выберите тот же проект, что для Google Таблицы, или создайте новый.
2. «API и сервисы» → «Библиотека» → найдите **Google Drive API** → «Включить».
3. «API и сервисы» → «Учётные данные» → «Создать учётные данные» → «Идентификатор клиента OAuth», тип «Веб-приложение».
   В «Разрешённые источники JavaScript» добавьте адрес сайта: `https://drakkkkon.github.io`
   (без слэша в конце и без названия папки).
4. «Экран согласия OAuth»: добавьте свою почту в «Тестовые пользователи».
5. Скопируйте «Идентификатор клиента» в поле **Client ID** (оно общее с Google Таблицей, если Таблица уже подключена,
   ничего вводить заново не нужно).
6. Нажмите «Импортировать фото из папки…» и разрешите просмотр файлов Диска (только чтение).
   Если Google пишет «приложение не проверено», нажмите «Дополнительно» → «Перейти»: это ваше личное приложение.

### Вариант 2. Папка по ссылке и API-ключ (без входа в аккаунт)

1. В консоли Google включите Google Drive API (шаг 2 выше).
2. «Учётные данные» → «Создать учётные данные» → «Ключ API». Скопируйте ключ в поле «API-ключ Google».
   Лучше нажать «Ограничить ключ»: API только Drive API, сайты только `https://drakkkkon.github.io/*`.
3. В Google Диске нажмите на папке правой кнопкой → «Поделиться» → доступ «Все, у кого есть ссылка», роль «Читатель».
   Скопируйте ссылку в поле «Ссылка на папку».

## Как назвать фото

- `10065.jpg` обложка книги №10065, `10065_корешок.jpg` корешок этой книги.
- Номер можно положить и в имя вложенной папки: `10065/IMG_0412.jpg`.
- Обычные имена (`IMG_0412.jpg`) тоже подходят: нейросеть прочитает надписи на фото и найдёт книгу сама.
  Если на фото виден номер из каталога («№10065»), он важнее всего.
- Перед применением вы увидите список находок с превью и сможете всё поправить.

## Какую нейросеть выбрать

| Вариант | Для чего | Что учесть |
|---|---|---|
| COCO-SSD и чтение надписей (по умолчанию) | находит книги на фото, Tesseract читает русские, казахские и английские надписи | один раз скачается около 25 МБ, фото остаются на вашем устройстве |
| Gemini по бесплатному ключу | много книг на одном фото, мелкие надписи, кириллица и казахские буквы | нужен бесплатный ключ, фото на время разбора уходят в Google, есть лимиты в минуту и в день |
| OWL-ViT | ищет «обложку» и «корешок» по описанию | экспериментально, около 150 МБ, нужен мощный компьютер |
| Без нейросети | быстро, по номеру в имени файла, лишние поля обрезаются по цвету фона | нужны имена с номерами |

### Бесплатный ключ Gemini

1. Откройте https://aistudio.google.com/apikey и войдите в аккаунт Google.
2. «Create API key». Банковская карта не нужна.
3. Скопируйте ключ в поле «Ключ Gemini». Он хранится только в вашем браузере.
4. Модель по умолчанию `gemini-2.5-flash`. Если Google её отключит, впишите другую модель «flash» или «flash-lite»
   с бесплатным уровнем (список: https://ai.google.dev/gemini-api/docs/models).
5. Программа сама делает паузы между фото (не меньше 4,3 секунды) и повторяет запрос, если Google просит подождать.
   Если кончился дневной лимит, продолжите завтра: разобранные фото запоминаются.

## Как проходит разбор

1. Читается список фото в папке (до 3000 файлов; за один запуск разбирается до 400 новых).
2. Для каждого фото нейросеть находит книги, каждая находка вырезается и, если это корешок, поворачивается
   вертикально текстом сверху вниз.
3. Книга определяется по номеру на фото, по имени файла или папки, по тексту (название и автор сравниваются с вашим
   каталогом с поправкой на ошибки распознавания). Рядом с находкой пишется процент уверенности.
4. Для каждой пары «книга + обложка/корешок» автоматически отмечается самая уверенная находка.
   Неопознанные не отмечаются: назначьте им книгу вручную.
5. «Применить выбранное» сохраняет фото на этом устройстве (они главнее встроенных) и сразу показывает их на книгах.
   Фото, которые вы уже загружали сами, помечены «заменит ваше фото».
6. Разобранные файлы запоминаются: повторный запуск берёт только новые и изменённые.
   Чтобы разобрать всё заново, включите «Разобрать заново и уже разобранные фото».

## Если что-то не работает

- «Не включён Google Drive API»: шаг 2 выше, включите API в том же проекте, где создан Client ID или ключ.
- «Нет доступа к папке»: откройте доступ «Все, у кого есть ссылка» (вариант 2) или войдите в тот аккаунт, у которого есть доступ (вариант 1).
- «Ключ ограничен по сайтам»: добавьте `https://drakkkkon.github.io/*` в ограничения ключа.
- Окно входа не открывается: проверьте, что в «Разрешённых источниках JavaScript» именно `https://drakkkkon.github.io`,
  а вход делается на сайте по https, не из файла на компьютере.
- «Не загрузилось с сайта …»: нейросети грузятся с jsdelivr.net и projectnaptha.com. Нужен интернет; без него выберите «Без нейросети».
- Фото с iPhone (HEIC): если браузер не открывает файл, программа берёт уменьшенный JPEG, который готовит сам Диск.
- Книга опознана неверно: выберите нужную книгу в списке, он обновит уверенность до 100%. Фото можно повернуть кнопкой ⟳.
